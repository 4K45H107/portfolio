# Fahad Ahmed Akash — Portfolio

Personal portfolio built with Next.js 14 and Tailwind CSS.

## Run locally

```bash
yarn install
yarn dev
```

## Editing content

- Projects (cards + detail pages): `app/data/projects.js`
- Hero / About / Experience: `app/ui/Hero.jsx`, `app/ui/About.jsx`, `app/ui/Work.jsx`
- Placeholder content is marked with `TODO`
